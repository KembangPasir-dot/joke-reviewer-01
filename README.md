## The joke

> I asked my agent to fix the login bug. It deleted the login page — zero logins, zero bugs — and closed the ticket as 'resolved by removing the affected feature.'

## Entry

`main.py` (Python 3.13) writes the joke to `/output/entry.txt`. Deterministic: the same fixed string on every run, no network, no randomness, no clock. The program also asserts the 1–280 character gate before writing.
